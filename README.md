# Week 3 – Password Cracking & Hash Analysis

## Project Overview

This project was completed as part of my Week 3 Cybersecurity Training at NetworkWalks.

The project focused on understanding password-cracking concepts, hash extraction, wordlist-based password recovery, and the practical use of cybersecurity tools in an authorized lab environment.

## Objectives

- Understand the fundamentals of password cracking.
- Extract password-protected PDF hashes.
- Perform wordlist-based password recovery.
- Gain hands-on experience with John the Ripper.
- Work with the RockYou wordlist.
- Practice password cracking using NetworkWalks tools.
- Document the process and results professionally.

## Modules Completed

### 1. Password Cracking with John the Ripper (JTR)

In this module, password-protected PDF files were analyzed and their crackable hashes were extracted.

The extracted hashes were then processed using **John the Ripper** with the **RockYou wordlist** to perform password recovery in the controlled training environment.

**Tools Used:**
- Kali Linux
- John the Ripper
- RockYou Wordlist

### 2. Password Cracking with NetworkWalks Tools

The second module involved using NetworkWalks' training tools to understand the complete password-cracking workflow.

The process included:

1. Uploading a password-protected PDF.
2. Extracting the corresponding crackable hash.
3. Performing wordlist-based password attempts.
4. Verifying successful password recovery.
5. Capturing the completion evidence.

**Tools Used:**
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
